# BIT101-macOS

BIT101-macOS 是一款面向北京理工大学学生的 macOS 校园助手客户端，基于 BIT101 开放接口打造，提供课程、成绩、校园信息与社区内容的统一入口。

## 项目简介

该项目目前以 SwiftUI 为主界面框架，结合 Apple 原生组件构建了一个适用于 macOS 的校园信息应用，目标是把教务、校园地图、社区内容与个人信息整合到一个简洁的桌面客户端中。

## 当前支持的功能

### 1. 登录与个人中心
- 支持统一身份认证登录
- 展示用户基本信息与个人资料
- 支持明暗主题切换

### 2. 课程与日程
- 课程表视图
- DDL 视图
- 空教室视图
- 目前仍在持续完善中，部分模块可能会根据接口能力继续扩展

### 3. 校园地图
- 使用 MapKit 展示校园地图
- 包含主要教学楼与校园场馆的标注

### 4. 学业相关
- 成绩查询
- 课程评价浏览
- 支持成绩数据的整理与展示逻辑

### 5. 社区与内容
- 话题列表与详情浏览
- 文章列表与详情浏览
- 支持分页加载与内容查看

## 技术栈

- 平台：macOS + SwiftUI
- 网络层：自定义 NetworkManager
- 加密：CommonCrypto（用于登录相关加密流程）
- 地图：MapKit
- 数据模型：Swift 结构体与 API 响应模型

## 项目结构

```text
BIT101-macOS/
├── BIT101_macOSApp.swift          # 应用入口
├── ContentView.swift              # 主界面与侧边栏导航
├── Models/                        # 数据模型
├── Services/                      # 网络与加密服务
├── Views/                         # 各功能页面
├── Assets.xcassets/               # 应用资源
└── BIT101-macOS.xcodeproj/        # Xcode 项目文件
```

## 如何运行

1. 使用 Xcode 打开项目文件夹中的 `BIT101-macOS.xcodeproj`
2. 选择 macOS 目标设备或模拟器
3. 点击运行按钮即可启动应用
